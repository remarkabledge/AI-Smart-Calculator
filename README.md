AI Smart Calculator
A browser-based calculator built with HTML, CSS, and JavaScript, powered by the math.js library for expression evaluation. It supports standard arithmetic, a quick AI-style natural language mode, and a running calculation history.

Features
Standard arithmetic: supports +, -, *, /, decimals, and parentheses.

Advanced operations: square (^) and square root (√) buttons.

Backspace and clear: easily edit or reset the current expression.

AI Mode: describe calculations in plain English (e.g., "square of 9", "add 20% of 150") and it converts them to math expressions.

Calculation history: every result is logged in a scrollable history panel.

Dark UI theme: modern gradient background with a responsive, button-based grid layout.

Live expression evaluation: uses the math.js library for safe and accurate parsing.

How to Use
Open index.html in any modern web browser.

Click the buttons (or type) to build an expression.

Press = to evaluate it, C to clear, or ← to backspace.

Click AI Mode 🤖 to enter a natural-language calculation prompt.

Tech Stack
HTML5: structure

CSS3: styling (grid layout, gradients, hover animations)

JavaScript (vanilla): logic and event handling

math.js (v11.8.0, via CDN): expression parser and evaluator
